# Quality Engineering Automation Challenge

Projeto de automação de testes desenvolvido como parte
de uma avaliação técnica de Quality Engineering.

## Tecnologias

- API: Python, Pytest e Playwright
- E2E: TypeScript, Playwright e Cucumber.js
- Mobile: Python e Appium
- Performance: k6
- CI/CD: GitHub Actions

## Estrutura

- `api/`: testes de API
- `web/`: testes E2E com BDD
- `mobile/`: testes automatizados Android
- `performance/`: testes de carga
- `docs/`: estratégia, matriz de testes e findings
- `scripts/`: comandos auxiliares
- `reports/`: resultados gerados localmente
- `.github/workflows/`: pipelines de CI/CD

## Instalação e execução

As instruções de instalação e execução serão
adicionadas conforme cada módulo for implementado.
